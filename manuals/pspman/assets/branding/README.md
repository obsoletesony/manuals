# Manual branding assets

- `PSPMAN3-owner-source.png` is the unmodified owner-supplied PSPMAN3 logo.
- `pspman3-cover-white.png` is a tightly cropped, proportionally resized
  2400x356 cover rendering generated from that source. Its transparency and
  visible artwork are preserved without reconstruction.
- `pspman-wordmark.svg` and `pspman-wordmark-white.png` are retained for other
  layouts that still use the earlier wordmark treatment.
