# Diagram sources

Most manual diagrams are original vector drawings generated by
`docs/manual/source/diagrams.py` and drawn directly into the PDFs.

The PSP front view uses `psp-2000-black-cc0.svg` as its source master. The
matching PNG is a high-resolution render cache used by ReportLab. The asset is
"PSP 2000 Black" by Todd Partridge - Gen2ly, originally published through
OpenClipart and dedicated to the public domain under CC0 1.0. Source and
license record:

https://commons.wikimedia.org/wiki/File:PSP_2000_Black.svg

The numbered control leaders are original PSPMAN manual artwork. The
consolidated manual uses the PSP control illustration and the installation
path diagram. The former audio-pipeline diagram was removed because the user
does not need decoder or playback-queue internals to operate PSPMAN.
